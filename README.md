# Pulse Studio

A small modern static website with CSS animation and a little JavaScript for menu, reveal, and pointer effects.

## Use

Open `index.html` in a browser, or publish this folder with GitHub Pages.

## Files

- `index.html` - page content
- `styles.css` - layout, theme, and animation
- `script.js` - mobile menu and reveal effects
- `favicon.svg` - site icon
